The second alpha of IPAForge. The macOS app now opens reliably and is signed with IPAForge's own certificate. Every file in the release comes with a verifiable signature. Please report problems in [Issues](https://github.com/SirReaDy/ipaforge/issues), with the logs attached (**Logs**, ⌘L / Ctrl+L).

## What's new

- **macOS opens reliably.**
  - The app is signed with IPAForge's own certificate, so the keychain trusts every future version after one **Always Allow**.
  - The window opens before the keychain is touched.
- **When the keychain can't be used:** Accounts says so, and your Apple IDs stay in memory until you quit.
- **More downloads:**
  - Windows `.msi`;
  - Linux `.deb` and `.rpm` for arm64;
  - a macOS `.zip` per architecture;
  - update metadata, for automatic updates later.
- **Signatures:** every file has a Sigstore signature (`<file>.sigstore.json`) proving it was built by this repository's release workflow.

## Before you start

- **macOS:**
  - IPAForge isn't notarised by Apple yet. Open it once, then go to *System Settings › Privacy & Security* and click **Open Anyway**.
  - When asked about *IPAForge Safe Storage*, click **Always Allow**.
- **Windows:**
  - SmartScreen warns about the download: click *More info › Run anyway*.
  - Install *Apple Devices* from the Microsoft Store first.
- **Linux:** install `usbmuxd`.
- **Your device:** iOS 15 or later with a passcode; on iOS 16 and later, Developer Mode must be on.

To check a download or the installed app, and for every step, see the [installation guide](https://github.com/SirReaDy/ipaforge/blob/main/docs/installing.md).
