The third alpha of IPAForge. It adds an **Apps** section that keeps your apps from expiring, app sources in the AltStore format, and a detailed view of each install. Please report problems in [Issues](https://github.com/SirReaDy/ipaforge/issues), with the logs attached (**Logs**, ⌘L / Ctrl+L).

## What's new

- **Apps:** the apps on your device signed with your Apple ID, with when each one expires.
  - **Refresh** works like SideStore's: while the certificate that signed an app is still valid, it only gets a new profile, so nothing is installed again. Otherwise it's installed again over the old app, keeping its data, and the run says why.
  - **Update** installs a newer version from the app's own source. **Remove** deletes it.
  - **Automatic refresh** while IPAForge is open: on by default, 2 days before an app expires.
  - Apps installed by IPAForge on another computer are recognised, and refreshed here too.
  - Apps installed by other tools with the same Apple ID are listed separately.
- **App sources:**
  - Preload reads sources in the AltStore format. The IPAForge catalog and SideStore's source are built in, and you can add others by link.
  - **Browse apps** shows every source's apps, with search, a source filter and the versions of each app.
- **Install progress in detail:**
  - downloads and transfers show their speed and time left;
  - requests to Apple show their progress, and iOS shows its own install percent;
  - the device line says USB or Wi-Fi, and installs over Wi-Fi are compressed.
- **Languages:** every translation has been reviewed.
- **Safety:** Refresh and Update only ever replace an app with the same app.

You can ignore the `.zip`, `.blockmap` and `latest*.yml` files: they are for automatic updates. Checksums are in `SHA256SUMS.txt`, and every file has a Sigstore signature (`<file>.sigstore.json`).

## Before you start

- **macOS:**
  - IPAForge isn't notarised by Apple yet. Open it once, then go to *System Settings › Privacy & Security* and click **Open Anyway**.
  - When asked about *IPAForge Safe Storage*, click **Always Allow**.
- **Windows:**
  - SmartScreen warns about the download: click *More info › Run anyway*.
  - Install *Apple Devices* from the Microsoft Store first.
- **Linux:** install `usbmuxd`.
- **Your device:** iOS 15 or later with a passcode; on iOS 16 and later, Developer Mode must be on.

To check a download or the installed app, and for every step, see the [installation guide](https://github.com/SirReaDy/ipaforge/blob/main/docs/installing.md).
