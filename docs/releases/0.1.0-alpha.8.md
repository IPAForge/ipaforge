A setup guide for your first launch, Wi-Fi installs without a cable and without usbmuxd, Apple TV and Vision Pro pairing, and an install fix for paid teams. Please report problems in [Issues](https://github.com/IPAForge/ipaforge/issues), with the logs attached (**Logs**, ⌘L / Ctrl+L), or ask on [Discord](https://discord.gg/kGJn7NC5Zf). IPAForge stays free; if it saves you time, you can support it on [Patreon](https://patreon.com/IPAForge).

## Updating

IPAForge 0.1.0-alpha.7 updates itself to this version when it opens: your Apple IDs, apps and settings stay.

## What's new

- **Setup guide and tour:** while no Apple ID is saved, IPAForge opens a guide that checks this computer and your iPhone, signs you in, installs SideStore, and lists what to do on the iPhone. A tour of the pages follows. **Finish later** brings the pages back, and **Settings › Setup guide** runs it again.
- **Wi-Fi without usbmuxd:** an iPhone this computer has used before is found on your network and reached directly, so Wi-Fi installs also work on Linux without usbmuxd and where the system's own Wi-Fi discovery misses the iPhone. Wi-Fi sync is turned on for you when a session opens.
- **The iOS 17.4+ tunnel, over USB and Wi-Fi:** installs and every other iPhone task can run through Apple's device tunnel, with no admin rights and no network adapter. IPAForge makes the remote pairing by cable the first time, so the iPhone then works on Wi-Fi once the cable is out.
- **Apple TV and Vision Pro:** **Pair Apple TV or Vision Pro…** on the Devices page pairs them with the code they show, and they get their own cards. Installing to them comes in a later version.
- **Settings in tabs.**

## Changed

- Expired apps whose profile iOS removed are still listed on the Apps page, as expired.

## Fixed

- Installing on a paid team no longer stops with the 10 App IDs limit: paid teams have no such limit.
- Refreshing an expired app whose profile iOS removed works, and an app whose App ID Apple removed is installed again, at the same version.
- An iPhone paired with more than one computer is found on Wi-Fi on iOS 26.4 and later.

## Known limits

- Apple TV and Vision Pro pairing and the Wi-Fi tunnel have only been tested with fakes and a few iPhones, not with every device.
- A paid team's plan can still say "0 left this week" for App IDs; it has no limit.

You can ignore the `.zip`, `.blockmap` and `latest*.yml` files: they are for automatic updates. Checksums are in `SHA256SUMS.txt`, and every file has a Sigstore signature (`<file>.sigstore.json`), which IPAForge also checks before installing an update.

## Before you start

- **macOS:**
  - IPAForge isn't notarised by Apple yet. Open it once, then go to *System Settings › Privacy & Security* and click **Open Anyway**.
  - When asked about *IPAForge Safe Storage*, click **Always Allow**.
- **Windows:**
  - SmartScreen warns about the download: click *More info › Run anyway*.
  - Install *Apple Devices* from the Microsoft Store first.
- **Linux:** install `usbmuxd`.
- **Your device:** iOS 15 or later with a passcode; on iOS 16 and later, Developer Mode must be on.

To check a download or the installed app, and for every step, see the [installation guide](https://github.com/IPAForge/ipaforge/blob/main/docs/installing.md).
