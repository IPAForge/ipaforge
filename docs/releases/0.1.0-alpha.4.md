The fourth alpha of IPAForge. SideStore looks after itself better, every iPhone gets a checklist, installing over Wi-Fi is faster, and **IPAForge now keeps itself up to date**. Please report problems in [Issues](https://github.com/SirReaDy/ipaforge/issues), with the logs attached (**Logs**, ⌘L / Ctrl+L).

## Updating from 0.1.0-alpha.3

Download and install this version once, over the one you have: your Apple IDs, apps and settings stay. From now on IPAForge updates itself when it opens (copies from the `.msi`, `.deb` or `.rpm` say when a new version is out, and which file to download).

## What's new

- **Automatic updates:**
  - IPAForge checks for a new version every time it opens. The macOS app, the Windows `.exe` and the AppImage download and install it by themselves, showing how far along they are, then open again.
  - Every update is checked before it installs: its file must carry the Sigstore signature IPAForge's release workflow made for that version. A file changed after the release, or not published by it, is refused.
  - Offline, IPAForge opens as it is and checks again next time. If a download fails: **Try again**, the release page, or use the version you have for now.
- **What's new:** after an update, what changed in plain words; every version's notes are under **What's new** at the foot of the sidebar.
- **Repair SideStore:** from SideStore's row in **Apps**, IPAForge checks, one line after another, what keeps SideStore from refreshing your apps by itself (who signed it, its certificate, its pairing file, when it expires) and fixes it in one go.
- **SideStore links and QR codes:** add a source you added here to SideStore on your iPhone by scanning a code (or all of them, one after another), or have SideStore install an app itself. Every app in **Browse apps** opens its details, the IPAForge catalog's too.
- **A checklist for each iPhone** on the **Devices** page: what it needs for its iOS version (Trust, a passcode, Developer Mode, trusting your Apple ID, LocalDevVPN for SideStore), ticked as you go.
- **Faster over Wi-Fi:** sending apps to the iPhone is about twice as fast.
- **Fixes:**
  - LiveContainer's apps can use its keychain again after installing it with IPAForge.
  - When Apple reports a negative number of App IDs left (a glitch on its side), **Try anyway** asks it to create them.
  - When an app is in several sources, IPAForge picks the one with the version on your iPhone, never an older one.
- **Company proxies and your own servers:** IPAForge trusts the certificates your system trusts, so HTTPS inspection or a self-hosted anisette server with its own certificate authority works.

| Linux, arm64 | `.AppImage` (arm64), `.deb` (arm64), `.rpm` (aarch64) |

You can ignore the `.zip`, `.blockmap` and `latest*.yml` files: they are for automatic updates. Checksums are in `SHA256SUMS.txt`, and every file has a Sigstore signature (`<file>.sigstore.json`), which IPAForge also checks before installing an update.

## Before you start

- **macOS:**
  - IPAForge isn't notarised by Apple yet. Open it once, then go to *System Settings › Privacy & Security* and click **Open Anyway**.
  - When asked about *IPAForge Safe Storage*, click **Always Allow**.
- **Windows:**
  - SmartScreen warns about the download: click *More info › Run anyway*.
  - Install *Apple Devices* from the Microsoft Store first.
- **Linux:** install `usbmuxd`.
- **Your device:** iOS 15 or later with a passcode; on iOS 16 and later, Developer Mode must be on.

To check a download or the installed app, and for every step, see the [installation guide](https://github.com/SirReaDy/ipaforge/blob/main/docs/installing.md).
