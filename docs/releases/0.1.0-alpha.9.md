A fix for the device check that could stay on "Checking the device..." for good, plus security updates to dependencies. Please report problems in [Issues](https://github.com/IPAForge/ipaforge/issues), with the logs attached (**Logs**, ⌘L / Ctrl+L), or ask on [Discord](https://discord.gg/kGJn7NC5Zf). IPAForge stays free; if it saves you time, you can support it on [Patreon](https://patreon.com/IPAForge).

## Updating

IPAForge 0.1.0-alpha.8 updates itself to this version when it opens: your Apple IDs, apps and settings stay.

## Fixed

- A device could stay on "Checking the device..." for good, on the Devices page and in the setup guide (seen on iOS 27). Making the remote pairing by cable now gives up after 8 seconds if the device never answers, and the session opens without it.
- Reading a device's status ends after 30 seconds with an error and **Check again**, instead of a spinner that never stops.

## Changed

- Dependencies updated to close the open security alerts: Electron 44.9.1, node-forge 1.4.3 and others.

## Known limits

- Apple TV and Vision Pro pairing and the Wi-Fi tunnel have only been tested with fakes and a few iPhones, not with every device.
- A device that never answers the remote pairing is not tried again until IPAForge is restarted.

You can ignore the `.zip`, `.blockmap` and `latest*.yml` files: they are for automatic updates. Checksums are in `SHA256SUMS.txt`, and every file has a Sigstore signature (`<file>.sigstore.json`), which IPAForge also checks before installing an update.

## Before you start

- **macOS:**
  - IPAForge isn't notarised by Apple yet. Open it once, then go to *System Settings › Privacy & Security* and click **Open Anyway**.
  - When asked about *IPAForge Safe Storage*, click **Always Allow**.
- **Windows:**
  - SmartScreen warns about the download: click *More info › Run anyway*.
  - Install *Apple Devices* from the Microsoft Store first.
- **Linux:** install `usbmuxd`.
- **Your device:** iOS 15 or later with a passcode; on iOS 16 and later, Developer Mode must be on.

To check a download or the installed app, and for every step, see the [installation guide](https://github.com/IPAForge/ipaforge/blob/main/docs/installing.md).
