## Updating

Download and install this version once, over the one you have: your Apple IDs, apps and settings stay. 0.1.0-alpha.4 can't update itself to it, because it only accepts releases from the repository's old address (it offers the release page instead). From this version on, IPAForge updates itself from its new home.

## What's new

- **A new home:** the code, the releases and the issues move to [github.com/IPAForge/ipaforge](https://github.com/IPAForge/ipaforge). Old links keep working.
- **Updates follow:** IPAForge now looks for new versions there, and installs only updates signed by IPAForge's release workflow.
- **A website:** [ipaforge.com](https://ipaforge.com), with what IPAForge does, the downloads and the roadmap.
- **A new licence:** IPAForge is now released under the **GNU AGPL-3.0** (or later). It stays free to use, study, change and share, and anything built from it, including a modified version offered as a service, must be open source under the same licence. Versions up to 0.1.0-alpha.4 remain under the MIT licence they were released with.

## Downloads

| System | File |
|---|---|
| macOS, Apple silicon | `IPAForge-0.1.0-alpha.5-mac-arm64.dmg` |
| macOS, Intel | `IPAForge-0.1.0-alpha.5-mac-x64.dmg` |
| Windows 10/11 | `IPAForge-0.1.0-alpha.5-win-x64.exe` (or `.msi`, which doesn't update itself) |
| Linux, x64 | `.AppImage` (x86_64), `.deb` (amd64), `.rpm` (x86_64) |
| Linux, arm64 | `.AppImage` (arm64), `.deb` (arm64), `.rpm` (aarch64) |

You can ignore the `.zip`, `.blockmap` and `latest*.yml` files: they are for automatic updates. Checksums are in `SHA256SUMS.txt`, and every file has a Sigstore signature (`<file>.sigstore.json`), which IPAForge also checks before installing an update.

## Before you start

- **macOS:**
  - IPAForge isn't notarised by Apple yet. Open it once, then go to *System Settings › Privacy & Security* and click **Open Anyway**.
  - When asked about *IPAForge Safe Storage*, click **Always Allow**.
- **Windows:**
  - SmartScreen warns about the download: click *More info › Run anyway*.
  - Install *Apple Devices* from the Microsoft Store first.
- **Linux:** install `usbmuxd`.
- **Your device:** iOS 15 or later with a passcode; on iOS 16 and later, Developer Mode must be on.

To check a download or the installed app, and for every step, see the [installation guide](https://github.com/IPAForge/ipaforge/blob/main/docs/installing.md).
