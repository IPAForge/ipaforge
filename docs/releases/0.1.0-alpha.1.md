**The first alpha of IPAForge, for testing.** It installs SideStore and your own apps onto an iPhone or iPad from Windows, macOS or Linux. Expect rough edges. Please report what breaks, with **Logs** attached (see below).

## What you can do

- **Install SideStore**, or LiveContainer with SideStore, from the Stable or Nightly channel. The pairing file and your signing certificate are placed in it automatically.
- **Preload apps:** drop `.ipa` files on the window, choose them, add a direct `.ipa` link, or pick from the catalog (LiveContainer, StikDebug, Feather). Each app is checked before anything changes, then they all install in one run.
- **Apple IDs:** sign in with two-factor authentication, using a trusted device, **Send a new code**, or a text message instead. Several Apple IDs can be saved, with a quick switch when one is blocked on a device.
- **Devices:** USB and Wi-Fi devices are listed, with what to do when one is locked, untrusted or has Developer Mode off.
- **When something fails:** a recovery screen with the fixes that apply, **Copy diagnostics**, **Show logs** and a pre-filled GitHub issue.
- **Logs** (⌘L or Ctrl+L): what the app did, searchable.
- Six languages (English, German, Romanian, Russian, Arabic, Japanese) and six colour themes.

## Opening it: this alpha isn't signed yet

Code signing comes before the first beta. Until then, your system warns the first time you open IPAForge:

- **macOS:** open the DMG and drag IPAForge to Applications. Opening it says Apple can't check it for malicious software; click **Done**. Then go to **System Settings › Privacy & Security**, scroll to *"IPAForge" was blocked*, and click **Open Anyway**. From Terminal, `xattr -dr com.apple.quarantine /Applications/IPAForge.app` does the same.
- **Windows:** SmartScreen says it protected your PC. Click **More info › Run anyway**.
- **Linux:** for the AppImage, `chmod +x IPAForge-*.AppImage` and run it. For a package, `sudo apt install ./IPAForge-*.deb` or `sudo dnf install ./IPAForge-*.rpm`.

## What you need

- **Windows:** **Apple Devices** from the Microsoft Store (or iTunes), so Windows can talk to the iPhone.
- **Linux:** `usbmuxd` from your package manager.
- **Every system:**
  - an Apple ID (a free one works);
  - an iPhone or iPad on iOS 15 or later, with a passcode;
  - a USB cable that carries data;
  - **Developer Mode** on, on iOS 16 and later. IPAForge shows the steps.

## Known limitations

- No automatic updates yet: download the next alpha from GitHub.
- No first-run setup guide yet. Start on **Install**, which says what to fix first.
- App sources (AltStore-format lists) and an **Installed apps** page come in the next alphas.
- Wi-Fi works for devices already paired over USB; pairing over Wi-Fi comes later.

## Reporting a problem

Open **Logs** (⌘L or Ctrl+L), switch on **Include debug details**, try again, then use **Save…** and attach the file to a [new issue](https://github.com/SirReaDy/ipaforge/issues/new). Logs never contain passwords, tokens or device identifiers, but they do name your device model, apps and team, so check before posting. When an install fails, **Report the problem** opens an issue with the diagnostics filled in.
